# QuickSwitch 使用说明

## 作用

QuickSwitch 可以把文件管理器中的目录快速送入 Windows 的打开/保存对话框，也可以通过 AutoSwitch 自动切换当前对话框目录。

支持的主要来源包括 Windows 文件资源管理器、Directory Opus、Total Commander、XYplorer、收藏夹和剪贴板路径。

## 安装

1. 从 [Fork Releases](https://github.com/xsnowfoxcode/QuickSwitch/releases/latest) 下载匹配系统架构的 `x64` 或 `x32` 压缩包。
2. 解压到一个固定目录，例如 `C:\Tools\QuickSwitch`。
3. 运行 `QuickSwitch.exe`。
4. 打开一个文件管理器目录，再在记事本或其他程序中打开文件对话框。
5. 按 `Ctrl+Q` 显示路径菜单，选择目录进行跳转。

## 常用操作

- `Ctrl+Q`：在文件对话框中显示路径菜单。
- `Ctrl+Shift+Win+0`：在没有文件对话框时强制显示菜单。
- 在设置中打开 `AutoSwitch`：文件对话框出现时自动切换到指定路径来源。
- `Pinned paths`：保存固定目录。
- `Clipboard paths`：将复制的目录临时加入当前文件对话框菜单。

## UNC 网络路径

网络共享目录必须保留两个开头的反斜杠，例如：

```text
\\server\share\QuickSwitch-main
```

v1.9.1 已修复从路径校验、资源管理器地址解析到最终自动跳转过程中丢失这两个反斜杠的问题。如果仍然无法跳转，请确认：

- 当前 Windows 账号可以直接访问该共享目录；
- 资源管理器中手动输入该路径能够打开；
- QuickSwitch 与目标程序运行权限一致；
- `Errors.log` 中没有权限或对话框控制失败信息。

## 日志与隐私

运行日志保存在程序目录的 `Errors.log`。日志可能包含本机路径、服务器名、窗口标题和进程名。提交 Issue 前请删除账号、机器名、网络共享名和其他敏感信息。
